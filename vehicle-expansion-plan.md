# Vehicle, destruction, audio, radio and display implementation plan

Scope: Direct3D 11 MiniCity3D. Preserve the OpenGL renderer and the user's existing save. Work in runnable milestones and record verification honestly.

1. **Vehicle systems:** extend the data-driven catalog with skateboard, bicycle (existing `bike` remains motorcycle), tractor, combine with rotating cutter/reel, tank, truck, trailer and fixed-wing airplane. Import detailed, human-authored online vehicle models with retained source, license and attribution; remove temporary procedural vehicle art. Add matching collision dimensions, distinct Jolt handling, rider positions, usable world spawns and HUD controls. Plane dynamics include thrust, airspeed-dependent lift, drag, stall, pitch/roll/yaw, landing gear and crash damage. Truck hitch is a physical constraint with attach/detach controls. Tank fires swept explosive projectiles with recoil and cooldown.
2. **Destruction:** exploding vehicles release bounded, colliding chassis/door/wheel/rotor/wing parts. Explosive building hits remove visible building volume and rebuild matching Jolt collision. Bullet traces, camera/character clearance and navigation respect holes. Damage is session-only; saves omit building holes and debris, load restores intact buildings.
3. **Audio:** separate weapon sound signatures; replace repeated engine noise bursts with a continuous, smoothly modulated engine voice and distinct powered/pedal/rotor/propeller/heavy vehicle profiles. Keep positional explosions and effects.
4. **Radio:** editable `data/radio.ini`, at least ten online presets sourced from broadcaster sites, asynchronous Windows streaming, wheel selection while driving, Off choice, status display, pause/exit/shutdown cleanup and saved station preference. Network failure must not block simulation.
5. **Display:** windowed, borderless and exclusive fullscreen with runtime menu selection, Alt+Enter shortcut, safe resize/focus handling, and persistence in settings and save files.
6. **Verification:** build MiniCity3D and run existing CTest suites plus deterministic regressions for new vehicle movement, airplane takeoff/stall/landing, trailer coupling, tank fire, physical fragments, building visual/collision holes and reset on load, radio parsing/selection, weapon/engine audio and display persistence. Run DX11 smoke captures for additions. Update controls, config documentation and `idea.md` only after checks pass.
