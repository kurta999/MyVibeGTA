# Surface materials

The 1K color and DirectX normal maps in this folder come from [ambientCG](https://ambientcg.com/) and are released under [CC0](https://docs.ambientcg.com/license/). The original material pages are:

- [Bricks001](https://ambientcg.com/view?id=Bricks001)
- [Concrete001](https://ambientcg.com/view?id=Concrete001)
- [Asphalt001](https://ambientcg.com/view?id=Asphalt001)
- [Bark001](https://ambientcg.com/view?id=Bark001)
- [Ground054](https://ambientcg.com/view?id=Ground054)
- [Fabric001](https://ambientcg.com/view?id=Fabric001)
- [Grass001](https://ambientcg.com/view?id=Grass001)
- [Metal001](https://ambientcg.com/view?id=Metal001)

These maps are bundled so the game runs offline. The source download archives contained additional maps and project files; only the color and NormalDX images used by the DX11 renderer are included here.
